# VideoCut

極簡純靜態影音工具網頁。完全於前端瀏覽器運算（WebAssembly），100% 靜態網站架構，無後端伺服器依賴。

## ✨ 核心功能（整合為兩大面板）

### 1. 影片處理 (分割 / 抽取 / 轉動畫)
只需上傳一次影片，即刻享有即時影片預覽與雙滑桿拖拉時間軸：
* **模式 A：剪切 / 抽取**
  - **抽取聲音**：抽取純音訊檔。
  - **抽取畫面**：抽取無聲影片檔。
  - **剪切片段**：快速切割選定時間區間。
* **模式 B：轉為動畫（一鍵切換）**
  - 共用同一個選取的影片與時間軸。
  - 可設定輸出格式（GIF / WebP）、解析度寬度與影格率（FPS）。

### 2. 合併影音
* 選取影片檔與聲音檔，一鍵合併封裝。

## 🚀 靜態網站使用與部署方式

因為所有處理都在前端瀏覽器內運算，這是一個 **純靜態網站（Pure Static Website）**：

### 1. 部署到 GitHub Pages（最推薦、永久免費）
1. 將本專案推送到您的 GitHub 倉庫（例如 `videoCut`）。
2. 在 GitHub 倉庫點擊 **Settings** -> **Pages**。
3. Branch 選擇 `main`（或 `master`），點擊 **Save**。
4. 幾秒後即可獲得專屬網址（例如 `https://<您的帳號>.github.io/videoCut/`），在任何電腦或手機打開都能直接使用！

### 2. 部署到 Vercel / Netlify / Cloudflare Pages
直接拖曳整個資料夾上傳，即刻發布為全球加速的靜態網站。

### 3. 本機測試
* 在 VS Code 中直接對 `index.html` 點右鍵選擇 **「Open with Live Server」**。
